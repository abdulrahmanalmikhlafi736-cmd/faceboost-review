# Faceboost Almekhlafi 2.18.2 🔥

**Faceboost بقاعدة Materialbook الهندسية المتينة + المحرك الذهبي F PRO 2.18.0 كاملاً كما هو.**

التطبيق النهائي المدمج: كل قوة مشروع [Ufoex/Faceboost](https://github.com/Ufoex/Faceboost) مع كل ميزات تطبيقنا محروسة في أصول المشروع بأسمائها الأصلية — مبني، موقّع، وجاهز.

## محركنا الذهبي — الأصول الأربعة (كما هي، بأسمائها الأصلية)

كلها في `app/src/main/assets/` وتُحقن عبر `utils/FproAssets.kt` مع استبدال عقدة `__CONFIG__` بإعدادات JSON حية:

| الملف | ما يحمله |
|---|---|
| `facebook.js` | شريط التقدم قوس قزح (`native-weld + stable-slot` — يلتحم بالبكسل مع الشريط الأصلي) + نظام الألوان (12 لوناً + تلقائي ديناميكي) + زر التنزيل العائم 44px + تحديد النص + ضغطتان لملء الشاشة + كود الإخفاء |
| `site-engine.js` | محرك التسريع متعدد المواقع (مصانع الإخفاء والألوان والتنزيل) |
| `audio-mode.js` | وضع «صوت فقط» — الفيديو يستمر صوتاً في الخلفية |
| `reference-engines.js` | محركات المرجع للسرعة |

## ما ورثناه من قاعدة Faceboost (بلا استثناء)

- PiP بنسب متعددة (4:7، 2:3، 3:4، 9:16) + صوت شاشة القفل بـ Media3
- طبقة رسائل ماسنجر داخل التطبيق مع المكالمات الصوتية والمرئية
- قائمة حظر Brave على مستوى الشبكة + adblock على مستوى DOM
- قفل التطبيق بالبصمة/PIN
- إشعارات فيسبوك الدورية + اختصارات الإطلاق
- المشاركة من وإلى التطبيق + إرسال كرسالة
- أزرار ريلز عائمة قابلة للسحب + تمرير تلقائي
- الوضع المغمور + إبقاء الشاشة + حجم النص 85–150%
- تصدير/استيراد الإعدادات (يشمل كل مفاتيح `fpro_*`)
- 16 ملف اختبار حقيقي + CI/CD يبني APK موقّعاً مع كل push

## إصلاحات 2.18.2 — الحارس الدائم 🫀

ملاحظة المالك الميدانية: «أجلس أقلّب فيديوهات فيختفي زر التنزيل وشريط التقدم نهائياً وما يرجعون إلا بإعادة تشغيل التطبيق».

التشخيص: كل مسارات الإحياء (ملاحظ الطفرات، أحداث التمرير، أحداث التشغيل) قابلة للموت بصمت داخل DOM فيسبوك المتقلب. خمسة مسارات قتل محددة:

1. **استثناء في تمريرة التلوين/الإخفاء** كان يجهض `scan()` قبل مرحلة إرفاق الفيديوهات — لا زر بعد ذلك أبداً. المرحلتان منفصلتان الآن بـtry/catch.
2. **استثناء في مُلاحِظ الطفرات** كان يمنع `requestScan()` نهائياً. المعالجة محصّنة الآن والطلب يصدر دائماً.
3. **تحديد نص قديم غير مرئي** يبقي `interactionBusy()=true` للأبد فتُؤجَّل كل الفحوص إلى الأبد. الحارس ينظّفه خلال نبضة (لا يمس تحديداً حياً).
4. **حوار معلّق خارج الشاشة** (drawer تعليقات مترجم) كان يُحسب «مفتوحاً» فيحجب كل الفيديوهات نهائياً. `visibleDialog()` يفحص الموقع الفعلي و`aria-hidden` الآن، والحجب لا يكون إلا بتغطية مركز الفيديو.
5. **خطأ ترتيب النقاط** في `layoutVideos` قد يُسقط الفيديو المشغَّل من `chosen` (طبقات إيماءات فيسبوك تحجبه عن `elementsFromPoint`). «بطل الشاشة» (المشغَّل الأكبر) مضمون في الاختيار الآن.

**الحارس الدائم**: نبض `setInterval` مستقل كل 1.2 ثانية لا يعتمد على أي سلسلة من السلاسل أعلاه — يجد بطل الشاشة (الفيديو المشغَّل الأكبر المرئي) ويضمن عبر `rescue()/kick()` أن زر التنزيل وشريط قوس قزح حاضران له، ويُعيد لحام العناصر المنفصلة عن جذر المستند، ويُشغّل فحصاً قسرياً إن تقادم آخر فحص. مُختبر بمتصفح حقيقي بسيناريوهات قتل كاملة (تجويع + تدوير DOM + طمس مباشر + حوار شبحي) واستعاد كل شيء في كل مرة.

## إصلاحات 2.18.1 (تقارير المالك الميدانية — الجولة السابقة)

1. **زر التنزيل كان يرفض كل الفيديوهات** برسالة «يلزم فتح الفيديو في فيسبوك»: دالة التسليم
   كانت تفحص متغيراً عاماً لا يُحدَّث أبداً بدل رابط الصفحة الحيّ. الآن الرابط الحقيقي
   للصفحة يسافر مع الطلب نفسه (الرئيسية وطبقة الرسائل معاً — إضافة مسار fpro:// كاملاً
   للطبقة)، مع تحديث الذاكرة الاحتياطية عند كل تنقّل.
2. **شريط قوس قزح «فوق زيادة» ثم ينزل عند الإيقاف**: المحرك `native-weld+shared-line`
   (إصدار 66) — أول مشغّل يقيس خط فيسبوك الأصلي يتعلّمه للجلسة كلها (ريلز/خلاصة
   منفصلين، محفوظ في localStorage): كل ريل جديد يوُلد على الخط نفسه من أول إطار،
   والفيديوهات التي لا شريط أصلي لها تجلس على الخط نفسه — صفر نزول مرئي.
